## 📌 Overview

S.A.N.A. Nova is a dual-mode personal assistant agent designed to handle
everything — from everyday tasks to high-level autonomous operations.

The agent operates in two distinct modes:

| Mode | Name | Trigger | Purpose |
|------|------|---------|---------|
| Normal | **Sana** | "Sana, ..." | Daily tasks, conversation, reminders, writing, search |
| Power | **Nova** | "Nova, ..." | High-level operations, complex analysis, unrestricted execution |
| Full | **S.A.N.A. Nova** | "S.A.N.A. Nova, ..." | Complete system, both modes combined |
